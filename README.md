# MeiGao-DPM

## 电动汽车电池充电数据集

原始数据和配套资料位于 [`data/battery-charging-data-of-on-road-electric-vehicles/`](data/battery-charging-data-of-on-road-electric-vehicles/)。

- 包含 `#1.rar` 至 `#20.rar`，分别对应 20 辆商用电动汽车约 29 个月的充电数据。
- 同时保留原仓库的 `README.md`、`LICENSE`、`capacity_extract.py`、两张图片及论文补充材料。
- 文件保持原样；可使用 7-Zip 或 WinRAR 解压 RAR 数据包。
- [来源及校验清单](DATA_SOURCE.md)

原作者要求使用该数据开展研究时引用以下论文：

Deng Z, Xu L, Liu H, Hu X, Duan Z, Xu Y. Prognostics of battery capacity based on charging data and data-driven methods for on-road vehicles. Applied Energy. 2023;339:120954.
